car-holder-plus

A simple model that creates a coaster with text on it. Three text options are available: - textContent: The main text on the coaster (adjust through textContentSize - default 16) - textSubContent: The subtext on the coaster (adjust through textSubContentSize - default 3) - textAround: The text around the outside edge of the coaster (adjust through textAroundSize - default 1)The coaster is designed to be printed on a flat surface, with the text on the outside edge of the coaster.
No [global_params]

Add global params via a heading at the top level of the config file:

                            [openscadgen.global_params]
                            params = { text="First,Second,Third", height=100 }
